# Homelab
Personal Homelab for self hosting, IT learning, networking, virtualization, and cybersecurity. 


The lab serves two purposes:
1. Build useful self-hosted services that I can use personally.
2. Create a hands on environment for learning IT, networking, system administration, virtualization, and cybersecurity.


## Planned Architecture

```text
Physical Server
└── Proxmox VE
    ├── Personal Services
    │   ├── ZimaOS
    │   ├── Photo Storage
    │   ├── Music Streaming
    │   ├── Media Streaming
    │   └── Minecraft Servers
    │
    ├── Learning Lab
    │   ├── Windows Server
    │   ├── Windows 11
    │   ├── Ubuntu Server
    │   └── Cybersecurity Labs
    │
    └── Networking
        ├── DNS
        ├── DHCP
        ├── VLANs
        └── Firewall Configuration
```
## Planned Services
